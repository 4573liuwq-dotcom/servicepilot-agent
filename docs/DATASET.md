# 售后智办数据集说明

本项目不包含真实用户、订单或支付数据。`CommerceStore.reset_demo()`会生成3条完全虚构的演示订单，日期相对运行当天计算，避免退款资格随时间失效。

| 订单 | 场景 | 金额 | 预期结果 |
|---|---|---:|---|
| EC2026001 | 送达3天、无理由退款 | 299元 | 超过200元阈值，暂停等待审批 |
| EC2026002 | 运输中、查询物流 | 89元 | 返回运单号，不产生业务动作 |
| EC2026003 | 送达30天、商品损坏 | 1299元 | 超过7天，转人工售后工单 |

售后政策位于`data/knowledge/`，包括七天无理由、质量问题、退款审批阈值等虚构规则。自动化测试将自然语言请求、订单状态和政策组合成回归样例，重点验证：意图路由、政策约束、人工审批、拒绝分支、幂等和安全护栏。

这些数据只用于教学与功能验收，不能代表真实平台业务分布，也不能据此宣称生产准确率。
